# JWorld

## Overview

JWorld is a text-based MMORPG-inspired adventure game developed in C. Instead of relying on graphics or animations, the game invites players to experience a vast fantasy world through descriptive storytelling, exploration, and imagination.

Every location, event, and interaction is presented through words, allowing players to create the world in their own minds. Inspired by classic text adventures and role-playing games, JWorld focuses on immersive narration rather than visual presentation.

## Features

* Text-based MMORPG-style adventure
* Exploration through descriptive storytelling
* Interactive choices and player-driven progression
* Fantasy-inspired world with multiple locations
* Lightweight and runs entirely in the command line
* Built using the C programming language

## Technology

* Language: C
* Interface: Command Line (Terminal)

## How to Run

1. Clone this repository.
2. Compile the source code using a C compiler.

```bash
gcc main.c -o jworld
```

3. Run the executable.

```bash
./jworld
```

> On Windows:

```bash
jworld.exe
```

## Project Vision

JWorld was created with the idea that imagination is the most powerful game engine. Rather than presenting detailed graphics, the game tells stories through carefully written descriptions, encouraging players to visualize every landscape, encounter, and adventure for themselves.

The long-term goal is to expand JWorld into a richer text-based MMORPG experience featuring quests, character progression, diverse regions, memorable NPCs, hidden secrets, and an evolving world shaped by player decisions.
